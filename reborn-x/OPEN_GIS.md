# Open GIS
Zero budget. No proprietary SDK or mandatory account.
- OpenStreetMap vector geometry: ODbL, attribution and derived database obligations.
- Kartverket open terrain and N50: verify dataset-level license before distribution.
- Norge i bilder: reference only until specific redistribution and derivative rights are confirmed. Never bulk-cache restricted tiles.
- Sentinel-2: open satellite imagery candidate, 10 m bands are regional reference, not container detail.
- QGIS, GDAL, PROJ, Blender, Godot: open-source processing tools.
- Original procedural textures where no redistributable aerial imagery exists.
- Retain source, license, acquisition date and resolution with each asset.
- Coordinate target EPSG:25832 with shared local origin; existing approximate map must be reprojected before merging.
- Never silently replace missing survey data with invented geometry.
