# Hardanger geographic data

Run `node tools/import-osm.mjs` from repository root using Node 18+. The bounding box is a provisional Norheimsund–Øystese region and must be verified. The output is raw geographic data, not yet a playable map. OpenStreetMap data © OpenStreetMap contributors, https://www.openstreetmap.org/copyright, ODbL 1.0. Keep source attribution visible in the game when used; review database redistribution obligations. Do not redistribute third-party aerial imagery without checking its license.
